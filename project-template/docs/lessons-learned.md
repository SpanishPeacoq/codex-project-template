# Lessons Learned

Read this file before debugging. Add an entry after fixing a bug, an incident,
or a process mistake that could happen again.

Keep each entry short. Link the issue or PR for details. Never include
secrets, account numbers, or personal data.

When a lesson applies beyond this project, propose it for the shared project
standard (the scaffolding repository) as well.

## Entry Format

```text
### YYYY-MM-DD: <short title>

- What happened:
- Root cause:
- Fix: <PR link>
- Rule to keep: <one sentence a future agent can follow>
```
